# WordPress Plugin

One-click content monetization for WordPress sites.

## Planned Features

- **One-click install** from the WordPress plugin directory
- **Auto-detects** your site's RSS feed URL
- **Dashboard widget** showing query count, revenue, and top articles
- **Settings page** for pricing, content controls, and wallet configuration
- **No code changes** — installs alongside your existing theme and plugins

## How It Will Work

1. Install the xpay plugin from WordPress admin → Plugins → Add New
2. Activate and connect your xpay account (API key)
3. Plugin auto-detects your RSS feed and creates an MCP server
4. Content is indexed and your endpoint goes live
5. Revenue appears in your WordPress dashboard and xpay dashboard

## Manual Setup (Available Now)

Until the plugin ships, you can set up your WordPress site in under 5 minutes:

1. Go to [app.xpay.sh/dashboard/charge-per-use/add-publisher](https://app.xpay.sh/dashboard/charge-per-use/add-publisher)
2. Paste your WordPress RSS feed URL (usually `https://yoursite.com/feed/`)
3. Review the detected articles and set your pricing
4. Configure your wallet and go live

Your WordPress site stays completely untouched — we read the RSS feed externally.

## WordPress RSS Feed URLs

| WordPress Setup | Feed URL |
|----------------|----------|
| Default | `https://yoursite.com/feed/` |
| Category feed | `https://yoursite.com/category/recipes/feed/` |
| Custom post type | `https://yoursite.com/feed/?post_type=recipe` |
| Yoast SEO sitemap | `https://yoursite.com/sitemap_index.xml` |

<Callout type="info">
Most WordPress sites have RSS enabled by default. If yours is disabled, you can re-enable it in Settings → Reading → check "Your site is visible to everyone."
</Callout>
