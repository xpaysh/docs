# Quick Start

Get up and running with \{xpay✦\} in under 5 minutes. This guide will help you make your first x402 payment and integrate agent spending controls.

## Overview

\{xpay✦\} provides three main ways to get started:

1. **🛡️ Agent Firewall** - Protect your agents from overspending
2. **⚡ API Monetization** - Start earning from your APIs immediately  
3. **📊 Transaction Monitoring** - Get visibility into agent payments

## Prerequisites

Before you begin, ensure you have:

- Node.js 18+ installed
- A crypto wallet (MetaMask, Coinbase Wallet, etc.)
- Some USDC on Base network for testing ([get free testnet USDC](https://faucet.circle.com/))

## Installation

Install the \{xpay✦\} Agent Kit:

```bash npm2yarn
npm install @xpay/agent-kit
```

Or install individual packages:

```bash npm2yarn
npm install @xpay/firewall
npm install @xpay/paywall  
npm install @xpay/explorer
```

## Your First Protected Agent Call

Let's create an agent that can make API calls safely with spending limits:

```typescript
import { XpayFirewall } from '@xpay/agent-kit'

// Initialize the firewall with spending limits
const firewall = new XpayFirewall({
  maxDailySpend: 100,     // Maximum $100 per day
  maxPerRequest: 5,       // Maximum $5 per request
  alertThreshold: 0.8,    // Alert at 80% of limits
  walletAddress: '0x...'  // Your agent's wallet
})

// Make a protected API call
async function callExpensiveAPI() {
  try {
    const response = await firewall.protectedFetch('https://api.openai.com/v1/chat/completions', {
      method: 'POST',
      headers: {
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        model: 'gpt-4',
        messages: [{ role: 'user', content: 'Hello world' }]
      })
    })
    
    const data = await response.json()
    console.log('AI Response:', data)
    
  } catch (error) {
    if (error.code === 'SPENDING_LIMIT_EXCEEDED') {
      console.log('Agent spending limit reached!')
    }
  }
}
```

## Your First Monetized API

Turn any existing API into a revenue stream:

```typescript
import { XpayPaywall } from '@xpay/agent-kit'
import express from 'express'

const app = express()

// Initialize paywall
const paywall = new XpayPaywall({
  pricePerRequest: 0.10,        // $0.10 per request
  receivingWallet: '0x...',     // Your wallet address
  facilitatorUrl: 'https://facilitator.base.org'
})

// Protect your API endpoint
app.get('/api/premium-data', paywall.middleware, (req, res) => {
  // This code only runs after payment is verified
  res.json({
    data: 'This is premium data worth $0.10',
    timestamp: new Date().toISOString()
  })
})

app.listen(3000, () => {
  console.log('Monetized API running on port 3000')
})
```

## Monitor Agent Transactions

Track all x402 payments in real-time:

```typescript
import { XpayExplorer } from '@xpay/agent-kit'

const explorer = new XpayExplorer({
  apiKey: 'your-xpay-api-key',
  projectId: 'your-project-id'
})

// Track all agent payments
explorer.trackAgent('agent-id-1', {
  name: 'Customer Support Bot',
  maxDailySpend: 50
})

// Get spending analytics
const analytics = await explorer.getSpendingAnalytics({
  timeframe: '24h',
  groupBy: 'agent'
})

console.log('Agent spending:', analytics)
```
