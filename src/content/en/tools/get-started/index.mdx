# Quick Start

Get from zero to your first tool call in under 3 minutes.

import { Steps, Callout } from 'nextra/components'

## Prerequisites

- Any MCP-compatible AI client (Cursor, Claude, VS Code, ChatGPT, etc.)
- That's it — no blockchain knowledge, no wallet setup, no SDK installation

<Steps>

### Get your API key

Sign up at [xpay.tools](https://xpay.tools) and grab your API key. Every new account gets **$5 in free credits**.

[Full guide →](/tools/get-started/get-api-key)

### Connect your client

Pick your AI client and paste the config. Each client has a one-step setup.

[See all clients →](/tools/connect)

### Make a tool call

Ask your AI agent to use a tool — it handles discovery, execution, and billing automatically.

[Walkthrough →](/tools/get-started/your-first-tool-call)

</Steps>

<Callout type="info">
**No wallet needed.** xpay✦ Tools uses a prepaid credit system. You top up with a credit card or crypto, and tool calls deduct from your balance.
</Callout>
