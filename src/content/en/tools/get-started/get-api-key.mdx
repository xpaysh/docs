# Get Your API Key

import { Steps, Callout } from 'nextra/components'

<Steps>

### Sign up

Go to [xpay.tools](https://xpay.tools) and sign in with your email or social account.

### Navigate to your account

Click your profile icon in the top right, then go to **Account** → **API Keys**.

### Create an API key

Click **Create Key**. Give it a name (e.g., "Cursor" or "Claude Code") and optionally set a spending limit.

### Copy your key

Your key will look like: `xpay_sk_...`

Copy it — you'll need it in the next step.

</Steps>

<Callout type="info">
Every new account gets **$5 in free credits** to try any tool on the platform.
</Callout>

## Spending Limits

You can set optional limits on each API key:

- **Per-call limit** — Maximum cost for a single tool call
- **Daily limit** — Maximum daily spend
- **Monthly limit** — Maximum monthly spend

These limits prevent unexpected charges. See [Spending Controls](/tools/guides/spending-controls) for details.
