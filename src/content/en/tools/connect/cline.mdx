# Cline

Connect xpay✦ Tools to [Cline](https://github.com/cline/cline) (VS Code extension).

## Prerequisites

- Cline extension for VS Code
- An [xpay API key](/tools/get-started/get-api-key)

## Setup

In Cline's MCP settings, add:

### Master Server (all tools)

```json
{
  "mcpServers": {
    "xpay": {
      "url": "https://mcp.xpay.sh/mcp?key=YOUR_API_KEY"
    }
  }
}
```

### Single Provider

```json
{
  "mcpServers": {
    "firecrawl": {
      "url": "https://firecrawl.mcp.xpay.sh/mcp?key=YOUR_API_KEY"
    }
  }
}
```

## Verify

1. Open Cline's MCP settings panel
2. Your server should show as connected
3. Ask Cline to use a tool from your connected server

## Troubleshooting

- **Server not connecting**: Ensure Cline supports remote HTTP MCP servers (recent versions)
- **Tools not listed**: Restart the Cline extension after adding the config
