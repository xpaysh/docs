# API / cURL

Call xpay✦ Tools directly via HTTP using the MCP JSON-RPC protocol.

import { Callout } from 'nextra/components'

## Prerequisites

- `curl` or any HTTP client
- An [xpay API key](/tools/get-started/get-api-key)

## List Available Tools

```bash
curl -X POST "https://mcp.xpay.sh/mcp?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"tools/list","id":1}'
```

## Call a Tool

```bash
curl -X POST "https://firecrawl.mcp.xpay.sh/mcp?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/call",
    "id": 2,
    "params": {
      "name": "firecrawl_scrape",
      "arguments": {
        "url": "https://example.com"
      }
    }
  }'
```

## Using the Master Server

With the master server, use the meta-tools:

### Discover tools

```bash
curl -X POST "https://mcp.xpay.sh/mcp?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/call",
    "id": 1,
    "params": {
      "name": "xpay_discover",
      "arguments": { "query": "web scraping" }
    }
  }'
```

### Check balance

```bash
curl -X POST "https://mcp.xpay.sh/mcp?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/call",
    "id": 1,
    "params": {
      "name": "xpay_balance",
      "arguments": {}
    }
  }'
```

<Callout>
The API uses the [MCP JSON-RPC protocol](https://modelcontextprotocol.io). All requests are `POST` with `Content-Type: application/json`.
</Callout>

## Response Format

Successful tool calls return:

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "...tool output...\n\nCost: $0.01 | Balance: $4.99 | xpay✦"
      }
    ]
  }
}
```
